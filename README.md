# OpenCampus 🎓

**A student productivity platform that keeps college life organized in one place.**

OpenCampus helps students manage their day: what class is next, whether they're on track with attendance, and what's due soon.

> 🚧 **Status:** Early development. Contributions and ideas are welcome.

## Features

| Feature | Description | Status |
|---|---|---|
| Smart timetable | Weekly class schedule with rooms, faculty and time slots | Planned |
| Next-class notifications | Alerts shortly before your next lecture | Planned |
| Attendance tracker | Per-subject attendance with percentage and "classes you can skip" estimate | Planned |
| Assignment reminders | Deadlines with reminders and completion tracking | Planned |
| Academic calendar | Exams, holidays and semester events in one view | Planned |
